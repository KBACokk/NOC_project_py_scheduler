# Отчёт по 9-й неделе: проверка сохранения результатов при выделении StatsManager

**Период:** Неделя 8 (08.11.2026–15.11.2026)  
**Объекты:** `SIMULATION_MANAGER.py`, `STATS_MANAGER.py`, контракты источников, история метрик и QoS.  
**Главная задача:** разделить оркестрацию симуляции и обработку статистики, сохранив результаты моделирования.


Отчёты за 7-ю и 8-ю недели уже описывают устранение AUD-001/AUD-002, вынос статистики, конфигурационный адаптер, обратную совместимость импортов, ограниченные очереди и подключение QoS. Эти работы не объявляются повторно выполненными на 9-й неделе.

## 1. Распределение ответственности

| Компонент | Ответственность |
|---|---|
| SimulationManager | Настройка симуляции, создание компонентов, глобальное время, последовательность TTI, вызов сбора и завершение прогона |
| StatsManager | Чтение снимков источников, проверка TTI и обязательных полей, агрегирование, детализация, хранение и экспорт |
| Scheduler / AMC / PDCCH | Решения по ресурсам, передаче данных, качеству канала и управляющим ресурсам |
| Buffer manager | Хранение, выдача и удаление пакетов, исходные QoS-счётчики |
| Конфигурационные классы | Преобразование пользовательских настроек и проверка ключевых параметров |

В текущем run_tti сохранена последовательность: обновление состояния UE -> обновление буферов -> генерация и постановка пакетов -> планирование. После завершения шага оркестратор вызывает сбор статистики при tti % collect_interval == 0.

Сравнение AST с предоставленным исходным монолитом подтвердило неизменность тела run_tti и большинства методов настройки. Это дополнительное статическое свидетельство, а не замена численному эксперименту.

## 2. Результаты контрольных прогонов

Использован сценарий sim_with_manager_qos: 5 UE, UMa, TDL включён, Layered Buffer, планировщик QosAware, набор Poisson-потоков с несколькими QCI из TEST_MODULES.py. Настройки одинаковы в обеих ветках сравнения.

Случайное состояние задавалось после импортов и до создания объектов: Python random, NumPy и GLOBALS.SEED.

|---|---:|---:|---|

### Метод сравнения

1. Каждая версия запускается в отдельном Python-процессе.
2. Снимки снимаются после выполнения каждого run_tti.
3. Из сравнения исключаются только поля с `time_us`: это измеренное время работы компьютера, а не физический результат симуляции.
4. Объекты UE в списке приоритетов представлены стабильным UE_ID. Адрес объекта в памяти между процессами не имеет физического смысла.
5. Типы NumPy приводятся к обычным числам и спискам; числовые допуски не применяются.
6. Для историй используется ключ TTI, чтобы отделить содержимое снимка от известного исправления дублирования collect.
7. Файловый лог заменён буфером в памяти; методы экспорта отключены в тестовой обвязке. Физический цикл и алгоритмы планирования не заменялись.

Первые технические сравнения выявили различие строковых адресов UE. После корректной нормализации по UE_ID это расхождение исчезло. Оно не являлось изменением результатов моделирования.

**Вывод:** для указанного QoS-сценария и двух начальных состояний декомпозиция сохранила наблюдаемые результаты моделирования на каждом из 5000 TTI. Агрегированные и детальные истории дополнительно совпали на прогонах по 300 TTI.

## 3. Границы подтверждённого результата

Не утверждается равенство всех возможных сценариев. Проверены QosAware, Layered Buffer, UMa/TDL и конкретные профили пяти UE. Отдельного покрытия всех восьми планировщиков, пустого трафика, других каналов, других длительностей и Simple Buffer в данном эксперименте нет.

Нормализация историй по TTI не доказывает отсутствие дублирующихся строк в исходной версии. Экспорт на диск и физическая корректность каждой формулы QoS отдельно не верифицировались. Равенство версий также не доказывает отсутствие у них общего дефекта.

## 4. Итог

Главная цель рефакторинга подтверждена в проверенном объёме: при одинаковой кодовой базе, настройках и начальном случайном состоянии выделение StatsManager не изменило наблюдаемые результаты двух прогонов по 5000 TTI. Содержимое трёх историй статистики совпало в дополнительных контрольных прогонах.
